# Benchmark fixture: conceptual queries against an apexyard-shaped corpus.
#
# One `query::expected/path` per line; `#` comments and blank lines ignored.
# Every query names the file that should be found, because recall cannot be
# measured without a known-correct answer — and a harness without recall
# rewards a mode for returning less.
#
# Six of the eight are deliberately conceptual: phrased the way someone asks a
# question, sharing few or no literal tokens with the target. Those are the
# ones lexical search cannot reach, and the reason the semantic arm exists.
#
# This file exists because the original 8-query run lived only in a shell
# history. A benchmark you cannot re-run is an anecdote.
